# CCAF Study Course

A step-by-step study site for the **Claude Certified Architect – Foundations** exam (CCAF, exam code CCAR-F).

**Study wiki (read on GitHub):** [wiki/](wiki/README.md): every module, FAQ, diagram and practice question as linked pages.

**Live site:** https://ppotdar.github.io/ccaf-study-course/ (once GitHub Pages is enabled)

## What's inside

| Module | What it covers |
| --- | --- |
| 1. Start here | Exam format, the 5 domains, the 6 scenarios, study plan |
| 2. The 10 rules | The principles that decide most questions, each with a worked example |
| 3–7. Domains | Every task statement as Concept → Exam answer → Trap, plus a quiz per domain |
| 8. Scenario playbook | Symptom → answer pattern for all six scenarios |
| 9. Cheat sheet | Files, flags, settings and signal words |
| 10. Practice exam | 104 scenario questions with explanations |
| 11. FAQ | Deep dives on the concepts that trip people up |

Progress and quiz answers are saved in your browser (localStorage) only.

## Question bank

[`ccaf_mcq_bank.csv`](ccaf_mcq_bank.csv) and [`ccaf_mcq_bank.json`](ccaf_mcq_bank.json): one row per question with `question, A, B, C, D, answer, explanation`, tagged by domain, task and scenario.

## Run locally

Open `index.html` in a browser. No build step.
